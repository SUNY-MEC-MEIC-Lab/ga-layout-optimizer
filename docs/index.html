    정답이 알려진 문제로 검증했습니다

    01–06 사례는 '가장 작은 배치' 가 무엇인지 아무도 모릅니다. 그래서 같은 탐색 엔진을 논문이 정답(더 나은 배치가 없음을 증명한 최적해)을 공개한 문제에 돌려, 엔진이 정답에 얼마나 가까이 가는지 쟀습니다. 문제와 비용식은 논문 그대로이고, 결과는 엔진과 별개인 검사로 실현가능한지 확인했습니다.

    숫자 읽는 법 — +1.5% 는 정답보다 1.5% 비싼 배치를 찾았다는 뜻입니다. 낮을수록 좋고, 0% 가 정답입니다. 증명된 정답보다 싼 답은 나올 수 없으므로, '논문보다 더 줄였다' 는 뜻이 아닙니다. 공정 플랜트·QAPLIB 는 기존 도면 없이 기기 목록만 주는 백지 배치 문제이고, 기존 배치를 줄이는 문제는 원전 계통(Wrigley) 하나입니다.

    다층 공정 플랜트 배치 Ejeh, Liu, Papageorgiou (2019), Comput. Chem. Eng. 131 · 부록 B 데이터

    이 엔진의 최선 배치층을 띄워 그림 · 마우스를 올리면 기기 이름

    비용 = 배관 + 펌핑 + 층 건설 + 땅값 (논문 식 10). 바닥 크기는 5 m 단위 후보 중에서 고르고, 같은 층 기기는 최소 이격을 지킵니다. LNG 는 압축기 3단 적층과 1층 50%·최상층 60% 비우기 조건까지 넣었습니다.

    기기가 많아질수록 차이가 커집니다. 증명된 최적보다 싼 해는 한 번도 나오지 않았습니다 — 비용식과 조건을 논문과 같게 구현했다는 하한 검사입니다.

    시설 배치 표준 문제 QAPLIB · 공개 최적해

    실제 원전 계통 배치 Wrigley et al. (2019) · Shearon Harris 데이터

    이 문제만 기존 배치를 줄이는 문제입니다 — 원래 발전소 배치 14,914 를 논문은 8,036(−46.1%)으로 줄였습니다(공개 미리보기에서 확인). 이 엔진은 −54.5% 가 나왔지만, 안전계통 배치·거리 정의가 논문 본문에만 있어 같은 조건이라고 확인할 수 없으므로 "논문보다 더 줄였다" 고 말하지 않습니다.
