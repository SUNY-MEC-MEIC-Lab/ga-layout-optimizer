# 기능 유지 요건 (`examples/function/*.json`)

면적을 줄이되 **각 공간이 역할을 할 수 있게** 하는 요건 묶음이다. `ga_update_ir` 패치로 그대로 적용된다
(`program` = 실 규모·동선 표시, `set.constraints` = 기능 제약, `set.weights` = hard 가중치, `set.search` = 탐색 설정).

| 파일 | 대상 | 근거 |
|---|---|---|
| `clinic_us.json` | 실제 의료·치과 클리닉 (미국, B 용도) | IBC 2021 Ch.10, ADA 2010, FGI OP 2018, CBC 2022 Ch.12 |
| `office_de.json` | 실제 연구소 건물 (독일) | ASR A1.2 · A1.8 · A2.3, MBO 2002 §33·35·36 |
| `hospital_or.json` | 가상 병원 수술부 | FGI 2014 (수술실), IBC 2021 Table 1020.3 (I-2) |
| `smr_aux.json` | 가상 SMR 보조건물 | IBC 2021 §1006.3 · §1007.1.1 · Table 1020.3 (+ 가정값 명시) |
| `chem_plant.json` | 가상 석유화학 플랜트 | CCPS 2018 (배치 원칙만 — 수치는 유료라 미확인, 가정값 명시) |
| `fpso_topside.json` | 가상 FPSO 상부 | 해양 기준은 유료라 미확인 — 가정값 명시 |

## 원칙

- **고정해야 하는 것은 없다.** 복도·계단·엘리베이터·배관대·크레인도 움직인다. 대신 역할을 제약으로 지킨다.
  - 복도 구간은 **없앨 수 있다**(`optional`) — 남은 복도로 모든 실이 출입 가능해야 하고(`CIRC-ACCESS`),
    층마다 복도·계단이 하나로 이어져야 한다(`CIRC-CONNECT`).
  - 계단·엘리베이터는 층마다 같은 자리에 쌓인 **수직 코어**로 움직인다 (`stack_cores`). 계단까지 피난 거리·
    계단 수·계단 간격을 지킨다(`EGRESS`).
  - 배관대는 12 m 구간으로 나눠 필요 없는 구간을 없앨 수 있고, 공정 설비는 배관대 가까이, 배관대는 끊기지
    않게(`RACK-SERVE`). 크레인은 적치장·구명정이 작업반경 안에 있게.
  - 예외는 FPSO 터렛 하나 — 선체의 계류점이라 상부 배치 문제에서 옮길 수 없다.
- **실 규모는 근거가 있는 실만 바꾼다.** 기준 면적보다 큰 실은 줄이고, 최소에 못 미치는 실은 키운다.
  인원·장비를 모르는 실(대기실·회의실·학생 사무실·실험실·치과 진료실 등)은 그대로 둔다.
  규칙에 `basis`(근거)가 없으면 `ga_update_ir` 가 거부한다.
- **검증된 값과 가정을 나눈다.** 확인하지 못한 수치는 `_why` 에 "가정" 이라고 적었다. 실제 적용 전 원문 대조 필요.
- **실제 건물이 통과하는 모델인지 먼저 본다.** 실제 클리닉 현황에 제약을 걸어, 지어져서 쓰이는 건물이
  제약을 거의 통과하도록 모델을 고쳤다(로비·대기실을 동선으로, 바깥 출입 실, 스위트 안 실 via_rooms 2,
  벽 두께 1.0 m). 남은 현황 위반은 모델 한계로 그대로 보고한다.

## 알려진 한계

- 피난 거리는 실 중심→계단 중심의 **직교거리**로 잰다 — 실제 보행거리의 하한이다.
- '어떤 실끼리 가까워야 하는가'(진료 동선 등)는 요건에 없다 — 출입·연결·피난만 지킨다.
- 석유화학 플랜트의 **도로·소방차 접근로**는 도면에 없어 고려하지 않았다 — 배관대 옆 통로를 접근로로 가정.
- 병원 수술부는 청결/일반 복도를 일부러 나눈 설계라 `CIRC-CONNECT` 를 쓰지 않는다.
